# Brand

**RavenBlack** is the mark. **GammaHEX-HQ** is the product — GUI and firmware for the Bitaxe Hex (6 ASIC).

The working title RavenMiner HQ is retired. Do not use it.

## Name

| Piece | Means |
| --- | --- |
| **Gamma** | Bitaxe Gamma — BM1370 class |
| **HEX** | Bitaxe Hex — six ASICs on one board |
| **HQ** | Command center. GUI and firmware, not a browser tab |

Write **GammaHEX-HQ** and **RavenBlack**. Leave Gamma Hex HQ, Raven Black, Raven-Black, and RavenMiner.

`Raven-Black00` is the GitHub handle only.
