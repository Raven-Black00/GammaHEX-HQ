# Changelog

## 1.0.0 — GammaHEX-HQ starting line

First public drop under the **RavenBlack** mark in this repo.

- Source file is `GammaHEX_HQ.py` (version lives in `_APP_VER`, not the filename).
- Engine is the Gamma Hex 1300 command center previously shipped as `GammaHex1300_5.9.3.11.py` / RavenMiner HQ 5.9.3.11.
- Window, tray, and dialog chrome say **GammaHEX-HQ**. Runtime JSON stays `ravenminer_*.json` so existing desks keep their IP and alert settings.

### Brand

- Lockup is **RavenBlack** (mark) over **GammaHEX-HQ** (product) with crimson underline.
- Repo banner and X header vectors live in `docs/brand/`.

## Lineage (retired names)

RavenMiner HQ and the 5.9.x desktop numbering are retired. They are the engine behind 1.0.0, not the product name.

The 5.9.3 patch set (CR9-1 … CR9-20), crash-fix 5.9.0.2, and earlier NerdQAxe → Gamma Hex work still live in the script header.
